# joshmedeski.com

## Blog posts

When you add new content to a post in `content/posts/` or restructure it, ask me whether to set
`updatedDate` in its frontmatter. Don't ask for typo fixes, formatting, or other small edits. When I
say yes, set it to today's date as a quoted string, `updatedDate: 'YYYY-MM-DD'`; the schema rejects an
unquoted date. The post header shows it as an "Updated" badge.
