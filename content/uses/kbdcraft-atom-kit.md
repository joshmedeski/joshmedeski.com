## Features

- Case built from LEGO-compatible bricks that you assemble yourself
- 64-key layout with arrow keys
- Hot-swappable sockets for MX-style switches
- Programmable with QMK firmware and the Vial configurator
- Ships as a kit with the PCB, switches, keycaps, and bricks
