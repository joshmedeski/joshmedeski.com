## Features

- Split halves you can place shoulder-width apart
- Ortholinear, column-staggered key layout
- Thumb clusters for keys like space, enter, and modifiers
- Tilt and tenting kit for a more natural wrist angle
- Fully programmable with ZSA's Oryx configurator (QMK)
