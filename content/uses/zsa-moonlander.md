## Features

- Split halves you can place shoulder-width apart
- Column-staggered, ortholinear key layout
- Adjustable thumb cluster that tilts to tent the keyboard
- Hot-swappable switches
- Detachable wrist rests and per-key RGB
- Fully programmable with ZSA's Oryx configurator (QMK)

[View on ZSA](https://www.zsa.io/moonlander)
